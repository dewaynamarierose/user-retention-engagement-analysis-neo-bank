# User Retention & Engagement Analysis with Neo Bank

Neo is a a Barcelona/London based fintech that helps businesses send money internationally and exchange currencies. Founded in 2017. Its mission is to eliminate hidden currency exchange fees. The goal of this analysis is to recognize what keeps users active and what why they become inactive in order to identify opportunities to improve.


## Executive Summary:

Using SQL, my team and I pulled real user, transaction, and notification data that was provided by LeWagon bootcamp and we analyzed user behavior, transaction habits, and retention patterns, then built an interactive Data Studio dashboard to present our findings.

## Business Problem:
Neo Bank wants to understand what makes users stay active and what causes others to stop using the bank. While attracting new users is important, signups alone do not tell us whether people continue using the bank. Neo Bank has data on user signups, transactions, subscription plans, and other user activity, but it is not clear which behaviors are associated with long term retention Our team's analysis aims to identify these patterns and help Neo Bank develop strategies to improve user engagement, reduce inactivity, and encourage users to continue using the bank.

## Methodology: 
1. Data Preparation: Explored and cleaned user, transaction, and notification data using SQL 
2. Data Modeling: Applied dbt-style conventions to organize data into staging, intermediate, and mart layers
3. Data Analysis: Analyzed transaction habits, user engagement, and retention patterns to understand what keeps users active
4. Dashboard Development: Built an interactive Data Studio dashboard to present key findings and recommendations
